### Quick Answers

**Q: Can I use Intel integrated graphics (Intel i7 13th gen, etc.)?**  
A: No. See [Integrated Graphics Compatibility](GRAPHICS_REQUIREMENTS.md#integrated-graphics-compatibility) for details.

**Q: What if I don't have a powerful gaming PC?**  
A: Use Shadow PC cloud gaming. See the [Shadow PC Setup Guide](SHADOW_PC_SETUP_EN.md).

**Q: What GPU do I need minimum?**  
A: NVIDIA GTX 1060 6GB or AMD RX 580 8GB minimum. RTX 3060 or RX 6600 XT recommended. See [GPU Compatibility Chart](GRAPHICS_REQUIREMENTS.md#gpu-compatibility-chart).

**Q: Will my laptop work?**  
A: Only if it has a dedicated GPU (GTX 1660 Ti or better). Integrated graphics won't work. See [Graphics Requirements](GRAPHICS_REQUIREMENTS.md).
