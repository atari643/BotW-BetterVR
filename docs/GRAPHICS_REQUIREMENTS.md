## Minimum Requirements

These are the **bare minimum** specs to run the mod. Expect compromises in visual quality and/or frame rate.

### Graphics Card
- **NVIDIA**: GTX 1060 6GB or GTX 1650 Super
- **AMD**: RX 580 8GB or RX 5500 XT 8GB
- **VRAM**: Minimum 6GB
- **API Support**: Vulkan 1.1 or higher (required)

### CPU
- **Intel**: i5-8400 or newer (6 cores, good single-thread performance)
- **AMD**: Ryzen 5 2600 or newer
- **Note**: Cemu is heavily single-threaded, so clock speed matters more than core count

### Memory
- **RAM**: 12 GB minimum
- **Storage**: 25 GB free space (for Cemu, game, and shader cache)

### VR Headset
- Any OpenXR-compatible headset
- Controller bindings currently optimized for Oculus Touch controllers

### Expected Performance
- **Resolution**: 1080p-1440p in graphic packs
- **Frame Rate**: 60-72 FPS
- **Settings**: Medium to Low settings in Cemu graphic packs
- **Experience**: Playable but not ideal for extended sessions

## CPU Requirements

### Why CPU Matters for Cemu

Cemu (the Wii U emulator) is **heavily dependent on single-threaded CPU performance**. The Wii U's PowerPC CPU needs to be emulated, and this happens primarily on a single CPU core. This means:

- **High clock speed > Core count**: A 4-core CPU at 4.5 GHz will outperform an 8-core CPU at 3.0 GHz for Cemu
- **Intel vs AMD**: Historically Intel had better single-thread performance, but modern Ryzen 5000/7000 series are competitive
- **VR adds overhead**: BetterVR adds additional CPU work for motion tracking, swing detection, etc.

### CPU Performance Tiers

#### ❌ Not Recommended
- Intel: i3 series (any generation)
- AMD: Ryzen 3 series, older FX series
- **Why**: Insufficient single-thread performance, will bottleneck GPU

#### ⚠️ Minimum
- Intel: i5-8400, i5-9400F (6 cores, ~4.0 GHz boost)
- AMD: Ryzen 5 2600, Ryzen 5 3600 (6 cores, ~4.2 GHz boost)
- **Expected**: 60 FPS with occasional drops in heavy scenes

#### ✅ Recommended
- Intel: i5-10400, i5-11400, i5-12400, i7-9700K, i7-10700K
- AMD: Ryzen 5 3600, Ryzen 5 5600, Ryzen 7 3700X, Ryzen 7 5700X
- **Expected**: Stable 90 FPS in most situations

#### ✅ Optimal
- Intel: i7-12700K, i9-12900K, i7-13700K, i9-13900K, i7-14700K
- AMD: Ryzen 7 5800X3D (excellent for emulation), Ryzen 9 5900X, Ryzen 7 7700X, Ryzen 9 7900X
- **Expected**: 120-144 FPS without bottlenecks

## Integrated Graphics Compatibility

### Intel Integrated Graphics (iGPU)

Many users ask if they can run BotW BetterVR on Intel integrated graphics. Here's the definitive answer:

#### Intel UHD/Iris Xe Graphics (10th-14th Gen Intel)

**Examples**: 
- Intel Iris Xe Graphics (11th-13th gen laptops)
- Intel UHD Graphics 630/730/770

**Compatibility**: ❌ **NOT COMPATIBLE**

**Reasons**:
1. **Insufficient performance**: 
   - Cemu requires 60+ FPS for playable VR
   - Intel iGPUs struggle to maintain even 30 FPS in BotW at low settings
   - VR requires rendering two viewpoints (stereo rendering), doubling GPU load

2. **VRAM limitations**:
   - iGPUs share system RAM
   - BotW BetterVR needs 6-8GB dedicated VRAM
   - Shared memory architecture creates bottlenecks

3. **Vulkan performance**:
   - While Intel iGPUs support Vulkan, performance is poor
   - Emulation + VR overhead exceeds iGPU capabilities

4. **VR encoding overhead**:
   - If using Virtual Desktop or Air Link, the GPU must also encode the VR stream
   - This adds 10-20% additional GPU load
   - iGPUs cannot handle both Cemu rendering + VR encoding

#### Specific Examples

| Processor | iGPU | Can Run BotW? | Can Run VR? |
|-----------|------|---------------|-------------|
| i7-13700K | UHD 770 | ⚠️ Maybe 30 FPS low settings | ❌ No |
| i7-12700H | Iris Xe 96EU | ⚠️ Maybe 25-30 FPS | ❌ No |
| i5-11400 | UHD 730 | ❌ No | ❌ No |
| i7-1165G7 | Iris Xe 96EU | ⚠️ Maybe 20-30 FPS | ❌ No |
| i9-13900K | UHD 770 | ⚠️ Maybe 35 FPS | ❌ No |

**Conclusion**: Even the most powerful Intel iGPUs (like UHD 770 in i9-13900K) **cannot run BotW BetterVR in VR mode**. You might run BotW in Cemu at low FPS, but VR is impossible.

### AMD Integrated Graphics (APU)

#### AMD Radeon Graphics (Ryzen APUs)

**Examples**:
- Ryzen 5 5600G (Radeon Graphics 7 cores)
- Ryzen 7 5700G (Radeon Graphics 8 cores)
- Ryzen 7 7700 (Radeon Graphics)

**Compatibility**: ❌ **NOT COMPATIBLE** for VR

AMD iGPUs are slightly more powerful than Intel iGPUs, but still insufficient:
- Might achieve 40-50 FPS in BotW non-VR at low settings
- VR mode is still not playable
- Same VRAM and encoding limitations as Intel iGPUs

## Cloud Gaming Solutions

If you don't have a powerful enough PC, **cloud gaming** is a viable alternative:

### ✅ Shadow PC (Recommended)

- **What it is**: Cloud gaming service with dedicated GPU
- **GPU**: NVIDIA GTX 1080 equivalent or better (depending on tier)
- **Compatibility**: ✅ Fully compatible with BetW BetterVR
- **Latency**: 20-40ms (acceptable for BotW)
- **Cost**: ~$30/month
- **Setup**: See [Shadow PC Setup Guide](SHADOW_PC_SETUP_EN.md)

**Pros**:
- Reliable performance
- Dedicated GPU
- Works with Virtual Desktop for Quest headsets

**Cons**:
- Monthly subscription cost
- Requires good internet connection (30+ Mbps)
- Some latency unavoidable

### ⚠️ GeForce NOW

- **Compatibility**: ❌ **Not supported**
- **Reason**: You cannot install custom mods/hooks on GeForce NOW
- Cemu itself may not be available on GeForce NOW

### ⚠️ Other Cloud Services

- **Xbox Cloud Gaming**: ❌ Not compatible (console games only)
- **Amazon Luna**: ❌ Not compatible (no custom PC software)
- **Paperspace/AWS GPU instances**: ✅ Possible but requires technical setup

## Performance Tips

### If you're on minimum specs:

1. **Lower resolution**: Use 1080p or even 720p in graphic packs
2. **Disable enhancements**: Turn off enhanced shadows, draw distance, etc.
3. **Limit FPS**: Set FPS++ to 60 or 72 instead of 90/120
4. **Reduce textures**: Use lower texture cache settings in Cemu

### If you have recommended specs or better:

1. **Increase resolution**: Try 1800p or 2160p for sharper visuals
2. **Enable FPS++**: Set to 120 or 144 FPS
3. **Max anisotropic filtering**: 16x for better texture quality
4. **Enable FXAA**: Nvidia FXAA for anti-aliasing

## Frequently Asked Questions

### Can I run this on a laptop?

**Answer**: Maybe, if the laptop has a **dedicated GPU** (GTX 1660 Ti or better). Gaming laptops with RTX 30/40 series mobile GPUs work well. Laptops with only integrated graphics cannot run this.

### My GPU is listed as minimum but I still get low FPS. Why?

**Answer**: Several possible reasons:
1. **CPU bottleneck**: Your CPU might not be fast enough (check single-thread performance)
2. **Wrong GPU selected**: Cemu might be using integrated graphics instead of dedicated GPU
3. **VSync enabled**: Make sure VSync is OFF in Cemu
4. **Power settings**: Laptop might be in power-saving mode instead of performance mode
5. **Thermal throttling**: GPU/CPU might be overheating and reducing performance

### Do I need an NVIDIA GPU or can I use AMD?

**Answer**: Both work! The mod had AMD compatibility issues in the past, but they're now fixed. AMD GPUs (RX 5700 and newer) work great.

### What about Mac/Apple Silicon?

**Answer**: ❌ Not compatible. Windows is required. Cemu does not run well on Mac, and BetterVR is Windows-only.
